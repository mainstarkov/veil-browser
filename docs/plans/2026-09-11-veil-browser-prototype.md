# Veil Browser Prototype Implementation Plan

> **For Codex:** Use `${SUPERPOWERS_SKILLS_ROOT}/skills/collaboration/executing-plans/SKILL.md` to implement this plan task-by-task.

**Goal:** Создать интерактивный веб-прототип приватного браузера с временной сессией, которая переживает обновление страницы и удаляется после закрытия вкладки.

**Architecture:** Одностраничный клиентский интерфейс на React внутри Next.js/vinext. Состояние вкладок, навигации, настроек и истории сериализуется только в `sessionStorage`; внешние страницы не встраиваются, а открываются отдельно с честным пояснением ограничения iframe.

**Tech Stack:** TypeScript, React 19, Next.js 16, vinext, CSS, Node test runner.

---

### Task 1: Сформировать оболочку браузера

**Files:**
- Create: `app/page.tsx`
- Modify: `app/layout.tsx`
- Modify: `app/globals.css`

**Steps:**
1. Добавить модели вкладки, истории и настроек приватности.
2. Собрать панель вкладок, адресную строку, кнопки навигации и стартовый экран.
3. Добавить адаптивную тёмную тему и отдельный цвет приватной вкладки.
4. Проверить клавиатурную отправку адреса и доступные подписи элементов.
5. Выполнить `npm run build`; ожидается успешная production-сборка.

### Task 2: Реализовать временную сессию

**Files:**
- Modify: `app/page.tsx`
- Test: `tests/rendered-html.test.mjs`

**Steps:**
1. Добавить проверку исходного кода на использование `sessionStorage`.
2. Восстанавливать вкладки, активную вкладку, историю и настройки при обновлении.
3. Добавить явную очистку временной сессии.
4. Выполнить `npm test`; ожидаются два пройденных теста.

### Task 3: Добавить демонстрацию приватности

**Files:**
- Modify: `app/page.tsx`
- Modify: `app/globals.css`

**Steps:**
1. Добавить панель с четырьмя переключателями защиты.

3. Пометить защитные функции как демонстрационные, чтобы не создавать ложных гарантий.
4. Для внешнего адреса показывать безопасную заглушку и ссылку открытия в новой вкладке.
