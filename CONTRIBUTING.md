# Участие в разработке

Veil Browser открыт для предложений и новых участников.

## Как присоединиться

1. Откройте раздел **Issues**.
2. Нажмите **New issue**.
3. Выберите форму **Заявка в команду**.
4. Расскажите, чем хотите заниматься, и дождитесь ответа владельца проекта.

После одобрения владелец отправит приглашение в collaborators. Оно даст право создавать ветки и отправлять изменения в репозиторий.

## Как предложить изменение без доступа

Сделайте fork репозитория, создайте отдельную ветку и отправьте Pull Request. Для небольших исправлений предварительное одобрение не требуется.

Не публикуйте в Issues и коде пароли, токены, ключи API и другие секретные данные.
