# Veil Browser

Интерактивный веб-прототип приватного браузера. Он демонстрирует вкладки, навигацию, приватный режим, центр защиты и историю временной сессии.

## Что уже работает

- вкладки и отдельная приватная вкладка;
- адресная строка, поиск, переходы назад и вперёд;
- история и настройки в `sessionStorage`;
- восстановление сессии после обновления страницы;
- удаление данных после закрытия вкладки браузера;
- ручная очистка сессии;
- адаптивный интерфейс.

## Важное ограничение

Это UI-прототип, а не анонимизирующий браузер. Переключатели защиты пока демонстрационные. Внешние сайты нельзя надёжно загружать внутрь обычного веб-сайта из-за `X-Frame-Options`, CSP и других браузерных ограничений.

Следующий практический этап — перенос интерфейса в отдельное приложение на Chromium/Electron или CEF. Настоящая приватность потребует сетевых политик, изоляции хранилищ, противодействия fingerprinting, контроля WebRTC, DNS и независимого аудита. Абсолютную анонимность гарантировать нельзя.

## Запуск

```bash
npm install
npm run dev
```

Затем откройте `http://localhost:3000`.
